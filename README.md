# aejn plugins

Claude Code plugins by aejn Studio.

| Plugin | What it does |
|---|---|
| [aejn-fivem-dev](plugins/aejn-fivem-dev) | Field-tested FiveM and GTA V development guidance: MLOs, maps, textures, clothing, vehicles, QBCore scripts, NUI and crash debugging. |
| [aejn-council](plugins/aejn-council) | Put an idea or decision to four independent AI advisors and a separate judge, and get one clear verdict. |

## Install

```
/plugin marketplace add aejnstudio/aejn-plugins
/plugin install aejn-fivem-dev@aejn-plugins
/plugin install aejn-council@aejn-plugins
```
